GuRouter is an AI API gateway that puts multiple model families behind a single endpoint. Change the
base URL and the key; keep the code you already wrote.

## What you can do

<div class="surf-grid">
	<section class="surf">
		<div class="surf-head">
			<Icon name="seti:http" size="1.25em" />
			<code class="surf-method surf-method--live">POST</code>
		</div>
		<h3 class="surf-title">Chat completions</h3>
		<p class="surf-body">
			<code>POST /v1/chat/completions</code> takes an OpenAI request body and returns an OpenAI
			response. Set <code>stream: true</code> for SSE. Your existing OpenAI SDKs work unchanged.
		</p>
		<a class="surf-more" href="/api/openai-compat/">OpenAI compatibility</a>
	</section>

	<section class="surf">
		<div class="surf-head">
			<Icon name="comment" size="1.25em" />
			<code class="surf-method surf-method--live">POST</code>
		</div>
		<h3 class="surf-title">Claude and Gemini</h3>
		<p class="surf-body">
			The same gateway routes Anthropic Messages and Gemini <code>generateContent</code> request
			shapes to their upstreams. Point Claude Code, Codex, or Gemini CLI at it and keep working.
		</p>
		<a class="surf-more" href="/getting-started/cli-setup/">CLI tools with CC Switch</a>
	</section>

	<section class="surf">
		<div class="surf-head">
			<Icon name="setting" size="1.25em" />
			<code class="surf-method surf-method--live">POST</code>
		</div>
		<h3 class="surf-title">SystemOne</h3>
		<p class="surf-body">
			<code>POST /v1/systemone</code> is not a chat and does not stream. Describe a situation once
			and get back a selected choice, a confidence score, and per-option probabilities.
		</p>
		<a class="surf-more" href="/api/systemone/">SystemOne reference</a>
	</section>
